# 界面规范、Design Tokens 与交互设计

## 1. 视觉原则

对标 App Store 年度写作应用标准：**静谧、低噪、高对比度阅读区、用层级替代冗长说明文案**。作者连续审稿数小时不刺眼，AI 能力按需展开，不常驻堆砌参数表单与悬浮按钮。

### 2.2 中文阅读排版标尺
- **UI 字体栈**：`"Inter", "PingFang SC", "Microsoft YaHei UI", sans-serif`
- **正文阅读字体栈**：`"Noto Serif SC", "Source Han Serif SC", "PingFang SC", "Microsoft YaHei", serif`（设置页支持一键切回无衬线码字字体）
- **等宽数据字体**（字数、Token、章节号）：`"JetBrains Mono", "Cascadia Mono", monospace`
- **正文版式参数**：
  - 居中正文栏最大宽度：`720px`（约每行 36–40 个汉字，符合人眼最佳扫视弧度）
  - 正文字号 / 行高：`17px` / `1.88`
  - 段落间距：`14px`，支持一键开关首行两字符缩进 (`text-indent: 2em`)

> 关键交互细节：当右侧抽屉收起（快捷键 `Ctrl+\`）时，正文画布自动完全居中进入极致专注审改态；文内虚线下划线点击即就地弹出手术 Diff 浮条，零弹窗遮挡正文视线。

### 3.3 设定账本（Atlas）

- **顶部置顶条**：专门固定展示「世界铁律（`is_invariant=1`）」，红色角标提示每章强制注入。
- **左分类筛选 + 章节时间轴滑块**：拖动顶部的「截至第 `N` 章世界快照」滑块，所有角色卡的境界、伤势、道具归属实时切换为第 `N` 章结束时的真实状态，彻底杜绝“翻设定集看到后期剧透”或查不清哪章开始吃书。
- **内置子页签**：`实体档案` / `伏笔看板`（按待收/临期/超期状态分组）/ `文风与去AI味规则`（导入样章查看 Style DNA 指标 + 开关或自定义 AI 味黑名单词条）。

### 3.4 模型与导出设置（Settings Modal）

- **供应商管理**：添加/测试多套 OpenAI 兼容（如 DeepSeek、OpenRouter、本地 Ollama）、Anthropic、Gemini 接口；Key 输入框保存后仅显示尾号掩码。
- **5 环节模型路由表**：单屏清晰列出 `大纲节拍(outline)`、`正文撰写(draft)`、`吃书与钩子审校(critic)`、`局部润色(polish)`、`记忆抽取(extract)` 各自绑定的供应商、模型名、温度与最大上下文估算。
- **本地工作区配置**：一键选择本地 Markdown 镜像导出目录、切换默认主题（深色护眼 / 暖纸浅色）、查看本地 SQLite 数据库路径与备份按钮。

## 4. 全局快捷键与边界态设计

### 4.1 核心快捷键
- `Ctrl + 1 / 2 / 3`：快速切换 `编排 / 审改 / 账本`
- `Ctrl + \`：折叠/展开审改台右侧抽屉
- `Ctrl + Enter`：在审改台触发生成当前章（生成中则触发平滑停止）
- `Ctrl + S`：立即保存正文并镜像导出 `.md`
- `Ctrl + Shift + F`：全局 FTS5 记忆检索引擎浮窗（支持双字人名与前文台词定位）
- `Alt + ] / [`：在审改台正文区逐个跳转下一个/上一个 AI 味或吃书告警位置

### 4.2 边界态与异常处理
1. **首次空书架态**：无任何多余营销介绍，居中极简两步引导：`1. 配置至少一个 API 供应商并测通` → `2. 创建第一本书（选玄幻/仙侠/都市）`。
2. **流式生成中断 / 崩溃恢复**：中途点击停止或遇到断网，后端先保留已生成全部内容并自动存一版快照，标记章节为 `partial`，提示区仅在底栏给出柔和状态条“已停在 1,420 字，可手动续写或重新生成”。
3. **429 / 上游超限错误**：绝不用弹窗强打断正在审阅的文字；在微批调度面板或审改台底栏显示具体错误原因（如 `DeepSeek 触发限流，已退避重试第 2 次`）与单键重试按钮。
4. **运行中关闭窗口保护**：若微批任务正在落库或正文有未保存修改，`OnBeforeQuit` 拦截后由 `app` 弹出原生确认并安全停稳所有协程再退出。
